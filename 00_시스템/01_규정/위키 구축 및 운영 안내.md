# 4 도구 실행

## 4.1 헤더와 연결 검사

- 도구 환경은 Python 3.9 이상이며 별도 패키지 설치 불필요함. 아래 명령은 위키 루트에서 실행함.
- `check`는 읽기 전용임. `apply`는 작업 대상인 위키 문서를 명시하여 실행하고 `90_작업 공간/중국출장`의 기존 파일은 대상으로 지정하지 않음.

```powershell
python "00_시스템/03_도구/heading_numbers.py" check
```

- 첫 번호 부여와 재계산은 [작업 절차: 헤더 번호 도구 실행](<작업 절차.md#33-헤더-번호-도구-실행>)의 `unnumbered`와 `numbered` 방식을 구분함.
- 도구 자체의 동봉 검증 코드는 다음 명령으로 실행함. Python 캐시를 남기지 않도록 `-B` 사용 가능함.

```powershell
python -B "00_시스템/03_도구/test_heading_numbers.py"
```

## 4.2 이미지 기록 검사

- 이미지와 통합 작업 기록을 실제로 작성한 경우 [이미지 생성 규칙: 최종 이미지와 통합 작업 기록](<이미지 생성 규칙.md#54-최종-이미지와-통합-작업-기록>)에 따라 검사함.
- 기록 검사 도구는 문자열, 규격, 해시와 연결을 대조함. 직접 시각 검수와 블라인드 전사를 대체하지 않음.
- 초기 구축에는 이미지와 이미지 작업 기록이 없으므로 실물 이미지 검증 대상 없음.

- 운영 지침, 공통 규정과 작업별 규칙, 색인, 새 월별 로그, 검증 도구와 Obsidian 설정 구성함.
