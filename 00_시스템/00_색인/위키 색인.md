# 1 목적

- 한국실감 위키의 역할별 문서 위치와 운영 규정에 진입하기 위한 색인임. 목록에 포함되었다는 이유로 자료의 채택이나 기획 출처 사용을 허용하지 않음.
- 기획 문서, 제작 자산과 산출물은 아직 등록하지 않음. 참고 자료에는 셀빅 회사 소개서와 K컬처실감 콘텐츠 소개서 등록. 작업 공간에는 중국 출장 준비 문서, 기존 사용자 자료와 관련 작업 기록 보관함.

# 3 폴더 안내

## 3.1 상위 폴더

| 폴더 | 역할 |
|---|---|
| `00_시스템` | 색인, 운영 규정, 작업 기록과 도구 |
| `01_프로젝트` | 과제 원본과 공식 기록 |
| `02_기획 근거` | 채택 결정과 적용 범위가 확인된 정보와 조건 |
| `03_기반 기획` | 상세 기획의 방향, 조건과 공통 규칙을 정의하는 기획 |
| `04_상세 기획` | 적용 가능한 기반 기획을 구체화한 기획 |
| `05_참고 자료` | 조사 원문, 사례와 참고용 분석 |
| `06_자산` | 제작하거나 가공한 이미지, 영상, 음원과 도표 등 |
| `07_프로토타입` | 검증용 구현과 검증 기록 |
| `08_산출물` | 위키를 이용해 만든 독립적인 사용, 전달과 발표용 파일 및 관리 기록 |
| `90_작업 공간` | 개인 초안, 아이디어, 대안 검토와 피드백 반영 작업 |
| `91_PDF 원본` | PDF 원본 보관 |
| `99_보관소` | 이전 기획, 종료 작업과 미채택 자료의 로컬 보관. Git 추적 제외 및 밖에서 내부로 연결하는 링크 금지 |

- 하위 폴더는 실제 보관 내용이 있을 때 생성함. 작업 공간에는 사용자가 이동한 `중국출장` 폴더가 있음.
- 작성 중인 기획서도 기반 또는 상세 기획 폴더에서 관리하며 파일 위치와 승인 상태를 구분함.

## 3.3 편집 환경과 기존 폴더

- `.obsidian`에는 원본에서 이식한 보관함 설정과 헤더 표시용 CSS 스니펫 보관함. 개인 세션과 열린 문서 상태는 이식하지 않음.
- [중국출장 작업 폴더](<../../90_작업 공간/중국출장/>): 출장 준비 문서, 사용자 제공 원본과 명함 제작 기록을 모은 위치. 중국 출장 관련 작업은 이 폴더 아래에서 관리.
- 해당 연결은 자료의 현재 위치 안내임. 기존 파일은 별도 변경 지시 전까지 보존하고 자료 내용을 기획 근거로 자동 채택하지 않음.

## 3.4 중국 출장 작업

- [출장 준비](<../../90_작업 공간/중국출장/출장 준비.md>): 출국 준비 체크리스트와 항목별 확인 방법.

- [선전 식당과 주점 안내](<../../90_작업 공간/중국출장/선전 식당과 주점 안내.md>): OT 안내 6곳과 추가 조사 6곳, 총 12곳의 메뉴, 위치와 가격 참고. OT의 가오더 QR 원본 링크와 방문 전 확인 사항 정리.
- [디지털 명함 제작 기록](<../../90_작업 공간/중국출장/명함/제작 기록/디지털 명함 제작 기록.md>): 명함 제작 상태와 검토 이미지 및 입력 원본 연결.
- [중문 소개페이지 번역 검수](<../../90_작업 공간/중국출장/중문 소개페이지 번역 검수/중문 소개페이지 번역 검수.md>): 중문 소개 이미지의 문구 전사와 회사 자료 2개 대조 기록. 총괄 논의 후 원본을 수정 없이 사용하기로 한 사용자 전달 결정과 미반영 수정안 보존.

## 3.5 회사 자료

- [셀빅 회사 소개서](<../../05_참고 자료/00_회사자료/셀빅 회사 소개서.md>): 회사 소개서 PDF 39쪽의 텍스트 정리. 회사 현황, 사업과 제품, 실적, 협력 기관 및 영상 링크를 원문 쪽수와 함께 관리.
- [K컬처실감 콘텐츠 소개서](<../../05_참고 자료/00_회사자료/K컬처실감 콘텐츠 소개서.md>): 국문 PDF 18쪽의 텍스트 정리. 한국실감 키오스크와 테이블의 납품 구성 및 체험 방법, 연계 포토타임과 추가 제품 포토그램AI를 원문 쪽수와 함께 관리.

# 4 문서 등록과 갱신

- 새 지식 문서와 기획서가 생성되면 역할별 위치와 실제 상태를 확인한 뒤 이 색인에 연결함.
- 사용과 전달용 파일, 제작 자산과 검토용 구현은 산출물 색인에 관리 기록과 함께 등록함.
- 실제 변경 작업은 해당 월의 로그에 기록함. 원본 위키의 문서 목록, 과거 로그와 산출물 목록은 이식하지 않음.
