# 1 이용 안내

- 사용, 전달과 발표용 파일 및 제작 자산과 검토용 구현을 한곳에서 찾기 위한 목록임. 관리 기준은 [위키 작업 지침: 사용과 전달용 산출물](<../../AGENTS.md#46-사용과-전달용-산출물>)과 [문서 형식: 산출물](<../01_규정/문서 형식.md#12-산출물>)을 따름.
- 별도로 사용하는 출력 파일과 관리 기록은 `08_산출물`에 보관함. 원본 문서, 제작 자산과 실행 프로젝트는 해당 역할의 위치를 유지하고 이 색인에서 연결함.
- 검토 상태, 파일 존재 여부, 내용 검증과 승인 여부는 각각 구분함. 파일의 생성이나 반환만으로 검토 상태를 높이지 않음.
- 원본 위키의 산출물과 `90_작업 공간/중국출장`의 기존 사용자 자료는 이 위키에서 생성한 산출물로 등록하지 않음. 기존 자료의 위치는 [위키 색인](<위키 색인.md>)에서 안내함.

# 2 사용과 전달용 파일

등록된 산출물 없음. 등록 시 산출물명, 용도, 정본과 관리 기록, 검토 상태와 파일 상태를 기록함.

# 3 제작 자산

등록된 제작 자산 없음. 등록 시 자산명, 실제 파일 위치, 관리 기록과 검토 상태를 기록함.

# 4 검토용 구현

등록된 프로토타입 없음. 등록 시 구현명, 프로젝트 위치, 설명과 검증 기록 및 미확인 범위를 기록함.

# 5 반환 대기와 보관 상태

- 반환 대기 파일 없음. 실물이 없는 파일은 열기 링크 대신 반환 예정 경로를 일반 텍스트로 기록함.
- 보관된 산출물 없음. 보관소 내부 경로는 링크로 연결하지 않음.
