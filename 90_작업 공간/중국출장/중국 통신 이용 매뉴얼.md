# 1 개인 휴대폰 로밍 상품 선택

휴대폰의 통신방식은 LG U+ 로밍으로 결정. 아래 상품은 선택을 위한 비교이며, 최종 상품과 가입 완료 여부는 아직 미확인.

**권장 판단:** 지도 검색, 위챗, 알리페이와 카카오톡 중심이면 로밍패스 4GB부터 검토. 사진과 업무 파일 전송이 많으면 13GB 검토. 사용량을 실측한 결과가 아닌 용도에 따른 제안이며, 4GB가 충분하다는 보장은 아님.

노트북 데이터는 와이파이도시락으로 별도 사용하므로, 아래 로밍 데이터는 휴대폰 사용량을 기준으로 선택.

| LG U+ 상품 | 온라인 신청 기준 총 데이터 | 총요금, 부가세 포함 | 이용기간 |
|---|---|---|---|
| 로밍패스 4GB | 4GB | 29,000원 | 최대 30일 |
| 아시아 로밍패스 7GB | 7GB | 39,000원 | 최대 30일 |
| 로밍패스 13GB | 13GB | 44,000원 | 최대 30일 |

표의 데이터는 하루 제공량이 아닌 기간 전체 총량. 온라인 추가 데이터 포함 여부는 신청 화면에서 확인. 중국은 세 상품의 이용 대상 국가. 요금 출처: [LG U+ 로밍 상품 목록](<https://www.lguplus.com/plan/roaming/all-plans/>)과 [온라인 추가 데이터 안내](<https://www.lguplus.com/plan/roaming/gnr/LRZ1007724>).

로밍패스는 해외에서 데이터를 처음 사용한 때부터 30일간 이용하며, 해외 데이터 또는 음성 통화를 한 번이라도 이용하면 상품 요금 발생. 기본량 소진 후 최대 400kbps로 계속 이용하므로, 업무 연결이 느려지면 잔여량부터 확인. [LG U+ 로밍패스 이용안내의 데이터와 요금안내](<https://www.lguplus.com/plan/roaming/term/LRZ1007724>)

# 2 개인 휴대폰 출국 전 신청과 준비

1. U+one 앱 또는 [LG U+ 해외 로밍](<https://www.lguplus.com/plan/roaming>)에 본인 회선으로 로그인. 중국 이용 가능 상품을 선택하고 최종 제공량, 총요금과 이용 조건 확인.
2. 신청 후 U+one의 해외 로밍 이용 현황에서 가입 상품 확인. 홈페이지 열람과 가입 완료를 구분하고 확인 화면을 휴대폰에 저장. 데이터 로밍 차단 부가서비스가 있다면 선택 상품을 이용할 수 있는 상태인지 확인.
3. 위챗과 알리페이의 로그인 및 필요한 본인 인증을 국내에서 마무리. 한국 번호의 문자 수신 준비와 국가번호 확인. 문자 수신은 무료지만 문자 발신과 일반 통화 요금은 별도 구분.
4. 한국이나 중국 현지로 음성통화할 예정이면 익시오 앱 설치 후 본인 회선 등록과 필요한 권한 확인. 본인 단말과 앱의 로밍콜 지원 여부도 출국 전에 확인.
5. 사진 자동 백업과 앱 자동 업데이트를 제한하고 회사 소개 영상과 발표 자료는 미리 저장. 노트북 사용 예정이면 [중국 통신 이용 매뉴얼: 노트북 와이파이도시락 이용](<#4-노트북-와이파이도시락-이용>)도 확인.

가입 확인과 충전은 [LG U+ 로밍 자주하는 질문](<https://www.lguplus.com/plan/roaming/support/faq>), 문자 수신과 고객센터는 [LG U+ 로밍 이용 방법](<https://www.lguplus.com/plan/roaming/guide?currentTab=TAB3>) 참고. 메뉴 이름은 기종과 앱 버전에 따라 달라질 수 있음.

| 통화와 문자 구분 | 로밍패스 가입 상태에서 확인한 조건 |
|---|---|
| 익시오 로밍콜로 한국 또는 중국 현지 음성통화 | 무료이며 로밍 데이터 제공량도 차감되지 않음. 제3국 발신과 영상통화는 무료 범위에서 제외 |
| 일반 전화 앱으로 받는 음성전화 | 무료 |
| 일반 전화 앱으로 거는 음성전화 | 분당 119원. 별도 과금 서비스는 해당 조건 확인 |
| 문자 수신 | 무료. 문자 발신은 별도 요금 확인 |

로밍은 해외에서 데이터, 전화와 문자를 이용하는 통신 서비스이며, 익시오는 전화 앱. 익시오 설치만으로 로밍 요금제에 가입되지 않으며, 위챗과 지도 등의 데이터 사용에 익시오가 필요한 것은 아님.

통화 조건은 [로밍패스 이용안내의 음성통화](<https://www.lguplus.com/plan/roaming/term/LRZ1007724>) 기준. 중국은 [익시오 로밍콜 이용 가능 국가 공지](<https://www.lguplus.com/plan/roaming/support/notice/1087728?pageNo=1>)에 포함. 로밍패스에 가입하지 않은 회선에 이 표의 통화 혜택을 그대로 적용하지 않음.

**출국 전 확인**

- [ ] 개인 휴대폰의 최종 LG U+ 로밍 상품 선택, 가입 완료 화면 저장.
- [ ] 로그인과 인증문자 수신 준비, 필요한 익시오 설정 확인.
- [x] 노트북용 중국 와이파이도시락 무제한 상품, 택배 수령으로 예약 완료. 사용자 전달 기준.
- [ ] 도시락 택배 실물 수령과 구성품 확인, 반납 기한 및 방법 확인.

# 3 선전 도착 후 개인 휴대폰 로밍 연결

1. 비행기에서 내린 뒤 비행기 모드 해제 후 휴대폰 재시작. LG U+ 회선이 켜져 있고 현지 통신망에 연결되는지 확인.
2. LG U+를 모바일 데이터 회선으로 선택하고 데이터 로밍 허용. 아래 예시 경로와 실제 기종의 같은 기능을 대조.
3. 와이파이를 끄고 브라우저에서 웹페이지를 열어 로밍 데이터 연결 확인.
4. 카카오톡 메시지와 사진 전송, 위챗 메시지, 고덕맵 장소 검색 및 알리페이 화면 갱신을 각각 확인. 알리페이 화면 연결과 실제 결제 승인은 구분.
5. U+one에서 가입 상품과 사용량 확인. 사용량 조회가 바로 갱신되지 않으면 시간차를 두고 재확인하고, 다른 상품 적용이나 오류가 보이면 고객센터 문의.

| 기기 | 데이터 로밍 설정 경로 예시 |
|---|---|
| 안드로이드 | 설정 → 연결 → 해외 로밍 → 데이터 로밍 사용 허용 |
| 아이폰 | 설정 → 셀룰러 → 사용하는 LG U+ 회선 또는 셀룰러 데이터 옵션 → 데이터 로밍 허용 |

설정 경로 출처: [LG U+ 로밍 자주하는 질문의 해외 도착 후 설정](<https://www.lguplus.com/plan/roaming/support/faq>). LG U+는 로밍 데이터로 중국에서 제한되는 구글 등의 사이트 이용이 가능하다고 안내함. 호텔 와이파이는 다른 접속 경로이므로, 업무 서비스가 열리지 않을 때는 와이파이를 끄고 로밍 데이터로 재확인. [LG U+ 로밍 이용 가이드의 인터넷 사용 비교](<https://www.lguplus.com/plan/roaming/guide>)

**현지 확인:** 연결과 앱 통신을 직접 확인한 뒤 기록. 국내 설치나 연결 시험만으로 현지 사용 완료 처리하지 않음.

# 4 노트북 와이파이도시락 이용

노트북은 **택배 수령으로 예약한 중국용 와이파이도시락 무제한 상품** 이용. 예약은 완료했으며 실물 수령과 현지 통신은 아직 미확인. 개인 휴대폰의 LG U+ 로밍 데이터와 별도로 사용.

와이파이도시락 공식 중국 상품 안내는 별도 우회 앱 없이 구글, 카카오톡 등의 이용이 가능하다고 설명함. 회사 업무 사이트와 보안 접속은 현지에서 별도 시험. [중국 상품 안내](<https://m.wifidosirak.com/Guide/majorcountry>)

## 4.1 예약 완료와 택배 수령

1. 예약 완료 안내를 저장하고 중국용 무제한 상품, 이용기간과 택배 수령 정보 대조. 이용기간이 출장 일정인 2026-11-23~26을 포함하는지 확인.
2. 택배 발송 안내와 운송장으로 배송 예정일 확인. 실제 수령일은 아직 미확인이며 특정 날짜 도착을 확정하지 않음.
3. 예약 내역에서 반납 기한과 방법 확인. 택배로 받는다는 이유만으로 반납도 택배라고 가정하지 않음.
4. 수령 시 단말기, 충전기와 케이블, 파우치 및 기종별 설명서 확인. 기기에 표시된 네트워크 이름(Wi-Fi ID)과 비밀번호(KEY)의 위치도 확인.

공식 택배 안내는 출국 1~2일 전 수령을 목표로 출고하며, 배송 시작 후 우체국택배 운송장 번호를 발송한다고 설명함. 주말과 공휴일에는 출고하지 않으며 배송 지연 가능. 실제 예약 건의 도착일은 발송 안내로 확인. [공식 택배 수령 안내](<https://m.wifidosirak.com/Reservation/ReceiptReturn?IsNew=3>)

구성품은 [공식 예약 및 이용 방법](<https://www.wifidosirak.com/v3/oversea_reservation?guide=down>)과 수령한 기기의 설명서 기준으로 확인.

## 4.2 중국 도착 후 노트북 연결

와이파이도시락은 해외 현지용으로 공식 안내상 한국에서 사용하거나 인터넷 연결 시험을 하지 않음. 국내에서는 예약, 구성품과 설명서를 확인하고 실제 통신 시험은 중국 도착 후 수행. [공식 설정 및 접속방법](<https://www.wifidosirak.com/v3/oversea_guide>)

1. 중국 도착 후 도시락 전원을 켜고 단말기 설명서에 따라 현지 통신망 연결 표시와 배터리 상태 확인.
2. 노트북의 와이파이를 켜고 기기에 적힌 Wi-Fi ID 선택.
3. KEY의 대소문자를 구분해 비밀번호 입력 후 연결 완료 확인.
4. 브라우저로 웹페이지를 열어 실제 인터넷 통신 확인. 이어서 필요한 업무 사이트와 파일 전송을 짧게 시험.
5. 인터넷 없이도 사용할 소개자료와 영상을 다시 확인. 연결에 문제가 있으면 [중국 통신 이용 매뉴얼: 노트북 와이파이도시락 문제](<#52-노트북-와이파이도시락-문제>)에 따라 점검.

연결 순서는 [공식 예약 및 이용 방법의 도시락 연결](<https://www.wifidosirak.com/v3/oversea_reservation?guide=down>) 참고. 노트북의 도시락 연결과 휴대폰의 LG U+ 로밍 연결은 별개로 확인.

## 4.3 사용 중 관리

- 단말기 한 대에 여러 노트북을 연결해 인터넷 공유 가능. 공식 중국 상품 안내상 최대 5명 동시 접속이며, 연결된 기기는 통신 속도와 데이터를 공유. 실제 기종의 접속 조건은 설명서로 확인. [중국 상품 안내의 동시접속](<https://m.wifidosirak.com/Guide/majorcountry>)
- 무제한 상품의 고속 데이터 제공량과 속도 제한 조건은 예약 내역에서 확인. 예약한 상품의 세부 조건을 직접 확인하지 않았으므로 고속 데이터가 계속 무제한이라고 단정하지 않음.
- 노트북의 대용량 업데이트와 클라우드 자동 동기화를 일시 중지하고 영상은 저장한 파일로 재생. 와이파이에 연결돼 있어도 도시락의 모바일 데이터를 사용한다는 점에 유의.
- 단말기를 충전하고 충전기와 케이블을 함께 준비. 사용 후 전원을 끄고 구성품을 한곳에 보관.
- 단말기는 배터리 내장 전자제품이므로 기내 휴대. 회사 노트북의 외부 네트워크 보안 정책으로 연결이 제한될 수 있으므로 필요한 설정은 회사 담당자에게 확인.

단말기 휴대와 회사 노트북 조건은 [공식 상품 유의사항](<https://m.wifidosirak.com/Reservation/notice>) 참고. 기종과 배터리 사용시간은 수령 기기의 안내 기준으로 확인.

# 5 연결 문제 해결

## 5.1 휴대폰 로밍 문제

| 증상 | 확인과 조치 순서 |
|---|---|
| 신호 없음 또는 서비스 없음 | 비행기 모드 해제와 LG U+ 회선 활성화 확인 → 재시작 → 네트워크 자동 선택 확인 → 계속 안 되면 고객센터에 현지 위치와 오류 전달 |
| 신호는 있으나 인터넷 불가 | 와이파이 끄기 → 모바일 데이터 회선과 데이터 로밍 허용 확인 → 가입 상품과 데이터 차단 여부 확인 |
| 호텔 와이파이에서 카카오톡이나 구글 이용 불가 | 로밍 데이터로 같은 기능 재시도. 로밍에서도 안 되면 다른 웹페이지와 비교하여 전체 연결 문제인지 특정 서비스 문제인지 구분 |
| 데이터가 갑자기 느려짐 | U+one 잔여량 확인. 기본량 소진이면 속도 제한 여부 확인 후 앱의 해외 로밍 이용 조회에서 충전 조건 검토 |
| 인증문자 수신 불가 | LG U+ 회선 활성화, 현지 통신망 연결, 국가번호와 수신 번호 확인 |

로밍 고객센터: 국내 **02-3416-7010**, 해외 **+82-2-3416-7010**. LG U+ 휴대폰에서 무료이며 24시간 운영. 상품명, 휴대폰 기종, 현재 위치와 오류 문구를 준비해 문의. 고객센터와 충전 방법 출처: [LG U+ 로밍 이용 방법](<https://www.lguplus.com/plan/roaming/guide?currentTab=TAB3>), [LG U+ 로밍 자주하는 질문](<https://www.lguplus.com/plan/roaming/support/faq>).


## 5.2 노트북 와이파이도시락 문제

| 증상 | 확인과 조치 순서 |
|---|---|
| 도시락 네트워크가 보이지 않거나 비밀번호 오류 | 단말기 전원과 배터리 확인 → 노트북 가까이 두기 → 기기에 적힌 Wi-Fi ID와 KEY 및 대소문자 재확인 |
| 와이파이는 연결됐으나 인터넷 불가 | 도시락의 현지 통신망 표시와 예약한 중국 상품 및 이용기간 확인 → 단말기 재시작 → 회사 보안 정책 확인 |
| 여러 노트북 사용 중 속도가 느려짐 | 대용량 전송과 자동 업데이트 중지 → 동시 접속 기기 수 확인 → 무제한 상품의 속도 제한 조건 확인 |
| 특정 업무 사이트만 이용 불가 | 다른 웹페이지와 비교하여 전체 통신 문제인지 구분. 회사 보안 접속이나 해당 서비스의 조건은 회사 담당자 또는 도시락 고객센터에 확인 |

해결되지 않으면 예약번호, 단말기 모델, 현재 위치와 오류 화면을 준비해 [와이파이도시락 고객센터](<https://www.wifidosirak.com/v3/customer_main>)에 문의. 재시작과 기종별 조치는 [공식 장애 해결 안내](<https://www.wifidosirak.com/v3/oversea_securityguide>) 및 수령 설명서에 따름.

# 6 귀국 후 확인과 검증 범위

- [ ] 와이파이도시락 단말기, 충전기와 케이블 및 파우치를 예약한 기한과 방식에 맞춰 반납하고 완료 확인.
- [ ] 개인 휴대폰의 LG U+ 국내 통신망 연결과 인터넷, 전화 및 문자 수신 확인.
- [ ] 로밍 사용량과 가입 상태 확인. 향후 해외 방문 시 상품이 자동 적용되는 조건이 있다면 유지 여부를 직접 확인.
- [ ] 다음 달 청구서에서 로밍 상품 요금과 별도 통화 및 문자 요금 대조. 이상 내역은 사용일과 가입 확인 화면을 준비해 고객센터 문의.

청구 시점은 [로밍패스 요금안내](<https://www.lguplus.com/plan/roaming/term/LRZ1007724>) 기준. 휴대폰 로밍과 노트북 도시락 이용 결정 및 도시락 무제한 상품의 택배 수령 예약 완료는 사용자 전달에 따라 반영. 예약번호, 실제 배송일, 세부 속도 조건과 반납 방법은 직접 확인하지 않음. 휴대폰 가입과 설정 변경, 현지 앱 접속, 익시오 통화 및 도시락을 통한 노트북 통신도 실행하지 않음. 상위 준비 체크리스트와 현지 사용 결과는 실제 확인 후 갱신.
