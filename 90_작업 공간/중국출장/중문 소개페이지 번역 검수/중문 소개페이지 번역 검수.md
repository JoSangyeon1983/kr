# 1 현재 진행 결정과 검수 결론

## 1.1 현재 진행 결정

- 결정: [기존 중문 소개페이지 JPG](<../연관자료/셀빅(CELLBIG)_소개페이지_중문최종본.jpg>)를 수정 없이 그대로 사용.
- 결정 근거: 2026-11-17 사용자가 총괄과 논의한 결과, 수정 없이 진행하기로 했다고 전달.
- 검수 제안 처리: 아래 수정 권고와 대체 문구는 검수 당시 이력으로 보존하며 이번 사용본에 반영하지 않음. 이 이미지의 추가 수정 작업은 진행하지 않음.
- 적용 범위: 해당 중문 소개 이미지의 사용 결정. 기존 검수의 사실 대조 결과와 확인 범위는 유지하며 회사 자료 2개의 내용과 상태를 변경하지 않음.

## 1.2 검수 당시 판단

- 검수 상태: 중문 본문 판독과 지정 문서 2개 대조 완료. 아래 수정안은 검토 제안이며 원본 JPG와 회사 문서에 미반영.
- 종합 판단: 회사의 사업 방향, Photogram AI의 촬영 및 출력, 주요 제품명과 던파 행사 사례는 대체로 국문 자료와 부합. 전면적인 오역으로 판단하지 않음.
- 검수 당시 수정 권고: `媒体洞穴`의 직역, `无需重新开发即可运营`의 무조건적 표현, 수상 내역 없는 `获奖情况` 제목, 한국문화 체험의 장비별 범위.
- 검수 당시 미확인 항목: 설립 일자, 담당자와 상세 주소, 연구개발 과제의 정식 명칭과 역할, 자체 제품 17종, Photogram AI 조달 등록과 번호, 한국문화 콘텐츠의 2027년 상용화 일정. 지정 문서에서 확인되지 않는다고 해서 거짓이나 오역으로 단정하지 않음.

## 2.2 수행 순서와 판정 기준

1. 이미지의 왼쪽 14쪽과 오른쪽 15쪽을 끝까지 읽고 위치별 문구에 C001~C051 식별자 부여. 최초 추출표를 저장한 뒤 검수 항목 구성.
2. 각 문구를 두 국문 문서의 해당 절과 대조. 제목, 표의 값, 한 문단 안의 개별 주장과 반복 문구를 구분.
3. 수치, 고유명사, 장비, 기능과 추진 상태의 차이 확인. 중국어 표현의 자연스러움은 사실 대조와 별도로 판단.
4. 수정 권고, 표현 개선, 자료만으로 판단할 수 없는 항목과 유지 가능한 항목으로 구분. 문제 위치, 근거와 대체 문구 기록.
5. 기록의 식별자 대응과 내부 링크, 원본 해시 및 헤더 번호 검증. 이미지 수정과 수정안의 회사 승인 여부는 별도 상태 유지.

- `자료 부합`: 지정 문서가 해당 의미를 뒷받침한다는 뜻. 외부 사실 입증을 의미하지 않음.
- `부분 확인`: 문구의 일부만 근거 확인. 확인되지 않은 나머지를 자동 보완하지 않음.
- `확인 필요`: 지정 문서만으로 판정 불가. 오류 확정 또는 임의 삭제의 근거로 사용하지 않음.
- `표현 개선`: 원문의 뜻을 이해할 수 있으나 중국어 어법, 정보의 명확성이나 표기 통일을 다듬는 제안.

# 3 검수 당시 수정 검토 문구

본 절과 다음 절의 제안은 원본을 수정 없이 사용한다는 현재 결정에 따라 미반영 이력으로 보존.

## 3.1 케이브 직역과 한국문화 체험의 범위

**대상 C039:** `通过互动桌与媒体洞穴，提供韩文、韩国画、料理、K-Pop、跆拳道及古宫体验`

- 현재 뜻: 인터랙티브 테이블과 미디어 동굴을 통해 한글, 한국화, 요리, K-POP, 태권도와 고궁 체험 제공.
- 용어 판단: `媒体洞穴`는 케이브를 물리적 동굴처럼 읽히게 하는 직역. `沉浸式体验空间（CAVE）`로 명료화 권고. 공식 중국어 제품명이 확인된 것은 아니며, 화면 구조나 투사 면수는 추가하지 않음.
- 범위 판단: [셀빅 회사 소개서: 한국 문화 실감 체험 콘텐츠](<../../../05_참고 자료/00_회사자료/셀빅 회사 소개서.md#43-한국-문화-실감-체험-콘텐츠>)에는 케이브 태권도와 테이블 요리, 캘리그라피, 한국화가 존재(원본 6, 10쪽). 따라서 태권도와 케이브 자체를 오역이나 잘못된 제품 추가로 판단하지 않음.
- 납품 구분: [K컬처실감 콘텐츠 소개서: 원문이 안내하는 납품 구성](<../../../05_참고 자료/00_회사자료/K컬처실감 콘텐츠 소개서.md#22-원문이-안내하는-납품-구성>)은 키오스크 1대의 5종과 테이블 1대의 3종을 명시(원본 1~3쪽). 태권도와 케이브는 이 기본 납품 목록에 없음. 현재 중문은 키오스크를 생략한 채 모든 주제가 테이블과 케이브에서 제공되는 듯 읽힐 여지가 있음.

회사 전체 제품군을 소개하는 현재 페이지에 맞춘 수정안:

> 通过互动桌、自助交互终端及沉浸式体验空间（CAVE），提供韩文、韩国绘画、韩国料理、K-POP、跆拳道与古宫等韩国文化主题体验。

이번 키오스크와 테이블 납품 구성만 설명하려는 경우의 별도 문구:

> 自助交互终端提供韩文、韩国料理、韩国绘画、K-POP与古宫主题内容；互动桌提供韩文书法、韩国料理制作与韩国绘画创作体验。

두 문구는 목적이 다른 대안. 첫 문구의 모든 주제가 모든 장비에서 실행된다는 뜻으로 사용하지 않으며, 둘째 문구에 케이브나 태권도를 기본 납품으로 추가하지 않음.

## 3.2 재개발 불필요의 무조건적 표현

**대상 C035:** `无需重新开发即可运营`

- 현재 뜻: 재개발 없이 바로 운영 가능.
- 판단: 브랜드 맞춤 구성은 확인되나, 모든 IP에 대한 재개발 불필요와 즉시 운영은 지정 문서에 없음. 기능 부재나 오역으로 확정하지 않으며, 적용 조건을 확인할 수 없는 단정적 표현으로 분류.
- 근거: [셀빅 회사 소개서: Photogram AI](<../../../05_참고 자료/00_회사자료/셀빅 회사 소개서.md#81-photogram-ai>)의 IP 맞춤 구성(원본 23쪽), [K컬처실감 콘텐츠 소개서: 스타일과 브랜드 맞춤 구성](<../../../05_참고 자료/00_회사자료/K컬처실감 콘텐츠 소개서.md#63-스타일과-브랜드-맞춤-구성>)의 프레임 및 화면 구성(원본 16~17쪽). 맞춤 제작의 범위, 비용과 일정은 미기재.

C032~C035를 함께 다듬은 수정안:

> 通过AI实现背景合成与画风转换，现场打印照片或照片卡，并可按品牌及IP需求定制滤镜、相框和界面。

- 수정 의미: AI 배경 합성과 화풍 변환, 현장 사진 및 포토카드 출력, 브랜드와 IP 맞춤 구성으로 한정.
- 기존 문구를 유지하려면 재개발이 불필요한 기능과 별도 설정, 제작 또는 개발이 필요한 범위를 회사에서 확인한 뒤 조건 명시.

## 3.3 수상 내역 없는 소제목

**대상 C018:** `商业化成果与获奖情况`

- 현재 뜻: 상용화 성과와 수상 현황.
- 판단: 바로 아래 C019~C022에는 제품 수, 조달 등록, 시장 점유율과 수행 사례만 있으며 상명, 연도와 수상 내역이 없음. 제목과 본문의 불일치.
- 수정안: `商业化成果与项目案例`.
- 근거와 선택: [셀빅 회사 소개서: 수상과 선정](<../../../05_참고 자료/00_회사자료/셀빅 회사 소개서.md#123-수상과-선정>)에는 수상 정보가 별도로 존재(원본 36쪽). 수상을 새로 추가하는 대신 현재 본문을 유지하는 최소 수정안 제시.

## 3.4 시장 점유율 1위의 비교 범위

**대상 C021:** `幼儿沉浸式内容Keezle在韩国教育科技沉浸式内容市场占有率位居第一`

- 현재 뜻: 유아 실감 콘텐츠 Keezle이 한국 에듀테크 실감 콘텐츠 시장 점유율 1위.
- 판단: [셀빅 회사 소개서: 키즐 Keezle](<../../../05_참고 자료/00_회사자료/셀빅 회사 소개서.md#71-키즐-keezle>)에 시장 점유율 1위 홍보 표현은 존재(원본 19쪽). 다만 시장의 경계, 수치, 조사기관과 조사 시점이 없어 중문의 넓은 시장 범위를 확인할 수 없음. 원자료에 있는 홍보 표현과 이번 검수의 사실 확인을 구분.
- 처리: 1위 표현과 시장 정의는 회사의 근거 확인 후 유지 여부 결정. 검수자가 문장을 다듬는 것만으로 입증된 수치가 되지 않음.

수치 근거가 제시된 보급 현황으로 바꾸는 별도 내용 수정안:

> Keezle已在韩国900多家幼儿园及托育机构安装使用。

위 대안도 회사 소개서가 제시한 설치 규모(원본 19쪽)에 근거한 표현. 외부 설치 실적을 독립 검증한 결과는 아니며, 현재 1위 문구의 직역 수정안과 구분.
