# 1 목적과 현재 상태

- 회사 공통으로 사용할 위챗용 세로형 디지털 명함 템플릿 제작.
- 작업 위치: [중국출장 Figma의 디지털 명함 페이지](<https://www.figma.com/design/EENvyucmDH5rGsEjnglkib?node-id=0-1>).
- 템플릿 디자인과 레이어 구성 완료. 공통 원본은 교체용 표시를 유지함. 직원별 인스턴스의 Jo Sangyeon과 조상연 및 기존 영문과 중문 소속과 직급을 보존하고, 한글 AI융합본부와 과장을 추가함. 현재 직원별 인스턴스에 등록된 QR 이미지와 QR 내부 안내 숨김 설정을 보존함. 상단에 홈페이지 주소와 검정 QR 원본을 추가함. 홈페이지 QR의 흰색 변환은 사용자가 직접 수행하기로 하여 색상 변경 없음.
- [제작 상태와 상세 출처 대응 기록](<제작 상태.json>), [검토용 미리보기](<검토/템플릿 미리보기 홈페이지 QR.png>).

# 3 Figma 구성

| 객체 | 노드 | 용도 |
|---|---|---|
| [공통 원본 컴포넌트](<https://www.figma.com/design/EENvyucmDH5rGsEjnglkib?node-id=5-28>) | 5:28 | 회사 공통 서식 관리 |
| [직원별 명함 내보내기 프레임](<https://www.figma.com/design/EENvyucmDH5rGsEjnglkib?node-id=5-49>) | 5:49 | 1080 x 1350 PNG 1x 출력 |
| 직원별 교체용 인스턴스 | 5:50 | 원본 컴포넌트에 연결된 복제본 |
| 개인 위챗 QR 이미지 교체 영역 | 원본 5:42 | 사방 여백을 포함한 320 x 320 전체 영역. 개인 QR을 FIT으로 적용 |
| 회사 홈페이지 주소 | 35:29 | 회사 공통 www.cellbig.com 표시 |
| 회사 홈페이지 QR 여백과 이미지 | 35:31, 35:32 | 여백 포함 198 x 198, 원본 PNG 본체 150 x 150. 사방 여백 각 24px |

이번 4:5와 QR 320은 사용자가 반영을 지시한 디자인 시안 값임. 위챗 공식 권장 규격이나 인식 보장값으로 취급하지 않음. QR 320은 코드 본체와 사방 여백을 합한 전체 영역이며, 실제 QR의 모듈 크기에 따라 사방 최소 4모듈의 빈 여백을 확보함. [DENSO WAVE 여백 기준](<https://www.qrcode.com/en/howto/code.html>) 참조.

- 편집용 텍스트 속성 8개: 이름 EN, 이름 KR, 소속 KR, 직급 KR, 소속 EN, 직급 EN, 소속 CN, 직급 CN.
- 표시 속성 2개: 한글 이름 표시, QR 안내 표시. QR 안내 표시는 QR 이미지 내부의 교체용 표시만 숨기며 하단 세 언어 안내는 유지함.
- 주요 텍스트 16개를 편집 가능한 레이어로 구성. 회사 전용 색상과 간격 변수 16개, 텍스트 스타일 17개 사용.
- 원본과 인스턴스의 구분 및 교체와 내보내기 순서는 Figma 캔버스에도 안내함.

소속과 직급은 독립 텍스트 속성이며 한글, 영문, 중문 순서의 3행과 소속 및 직급의 2열을 공유하는 네이티브 그리드로 구성. 두 열은 내용 너비에 맞춰 자동 조정하며, 세 언어 중 가장 넓은 소속명 뒤에 직급 열 전체가 함께 배치됨. 소속 열의 최대 텍스트 폭은 660px, 직급 열은 204px, 열 간격은 24px. 각 행 높이도 내용에 맞춰 자동 조정하며 소속명이 줄바꿈되면 다음 언어의 행이 내려감. 직급은 해당 언어 소속의 첫 줄 높이에 맞춰 배치. 소속은 보통 굵기의 회색, 직급은 중간 굵기의 진한 색상 유지.

현재 직원별 인스턴스에는 한글 AI융합본부와 과장, 영문 AI Convergence Division과 Manager, 중문 人工智能融合事业部와 经理가 입력되어 있음. 기존 입력값과 독립 편집 속성 보존. 회사 공식 번역 승인 여부는 별도 확인하지 않음.

QR 하단 안내도 한글, 영문, 중문 순서로 배치함. 문구는 한글 스캔하여 위챗 친구 추가, 영문 Scan to connect on WeChat, 중문 扫码添加微信. 세 언어 모두 보통 굵기의 회색으로 정리하며 국문과 중문은 30px, 영문은 28px로 맞춤. 개인 정보와 위챗 QR 사이 간격은 40px 유지. 명함과 개인 위챗 QR 전체 영역 크기도 유지.

상단 브랜드 영역은 높이 288px의 가로 자동 레이아웃으로 구성. 왼쪽은 가로 520px 로고와 홈페이지 주소, 오른쪽은 여백 포함 198px 홈페이지 QR과 Website 안내를 배치함. 회사 홈페이지 QR은 제공된 검정 PNG 원본을 업로드하여 내용과 색상 유지. 홈페이지 QR의 흰색 변환은 사용자 담당.

# 4 검증 결과와 한계

- 입력 PDF와 로고 및 홈페이지 QR PNG의 수정 전후 SHA-256 일치. 원본 파일 미변경.
- 원본 컴포넌트와 직원별 인스턴스의 연결, 텍스트 속성 8개와 표시 속성 2개 확인. 기존 이름, 세 언어 소속과 직급, 표시 속성과 QR 이미지 채우기 보존.
- 로고 이미지 채우기, FIT과 원본 비율, 주요 텍스트의 스타일 및 색상 변수 바인딩 확인.
- 1080 x 1350 최신 미리보기 직접 확인. 세 언어 직급의 왼쪽 시작점이 공통 세로선에 맞춰 배치되며 로고, 이름, 소속과 직급, QR 및 하단 안내의 잘림과 겹침 없음. 별도 임시 인스턴스의 속성에서 짧은 소속명, 현재 소속명, 긴 영문 소속명, 다시 짧은 소속명 순서로 변경하여 검증. 직급 시작점이 소속 폭에 따라 함께 이동하고 다시 줄어들며, 긴 영문 소속은 두 줄로 바뀌고 중문 행이 자동으로 내려감을 확인. 모든 사례에서 직급 시작점 일치와 명함 영역 내 배치 확인 후 임시 노드 제거. 다른 직원별 문구는 교체 후 재검수 필요.
- 현재 직원별 위챗 QR 이미지와 표시 설정 보존. 상단 홈페이지 QR은 새 미리보기의 실제 198px 영역에서 OpenCV로 해독한 URL이 원본 http://www.cellbig.com과 일치함을 확인. 홈페이지 QR 사방 여백은 각 24px로 코드 4모듈에 해당. 위챗 실기기 인식, 친구 추가와 중국 내 홈페이지 접속 검증은 미실행.

홈페이지 추가 전의 [직급 자동 정렬 미리보기](<검토/템플릿 미리보기 직급 자동 정렬.png>), 공통 열 자동 정렬 전의 [QR 다국어 안내 미리보기](<검토/템플릿 미리보기 QR 다국어 안내.png>), QR 안내 확장 전의 [소속과 직급 세 언어 미리보기](<검토/템플릿 미리보기 한글 영문 중문.png>), 한글 추가 전의 [소속과 직급 분리 미리보기](<검토/템플릿 미리보기 소속 직급 분리.png>)와 소속과 직급 분리 전의 [4대5 미리보기](<검토/템플릿 미리보기 4대5.png>)는 이전 검토 기록으로 보존함. 이전 1080 x 1440 시안과 당시 검토 결과는 제작 상태 JSON의 history에 보존함. [이전 미리보기](<검토/템플릿 미리보기.png>)는 이전 시안의 검토 기록이며 현재 출력 기준으로 사용하지 않음.

# 5 직원별 사용 방법

1. 직원별 교체용 인스턴스 또는 해당 내보내기 프레임을 복제. 상단 홈페이지 주소와 홈페이지 QR은 회사 공통 정보로 유지.
2. 인스턴스 속성에서 이름 EN과 이름 KR, 소속 KR과 직급 KR, 소속 EN과 직급 EN, 소속 CN과 직급 CN을 각각 입력. 소속명 변경 시 직급 열과 행 높이가 자동으로 조정되므로 별도 위치 보정은 필요하지 않음. 필요한 경우 한글 이름 표시 해제.
3. 여백 포함 320 x 320 QR 영역에 실제 개인 위챗 QR을 맞춤(FIT)으로 적용. 원본 여백을 보존하고 사방 최소 4모듈 확보 여부를 확인한 뒤 QR 안내 표시 해제. 이 속성은 QR 이미지 안의 교체용 표시만 숨기며 하단 세 언어 안내에는 적용하지 않음.
4. PNG 1x로 출력한 뒤 휴대폰 화면을 다른 기기로 스캔하는 경우와 위챗으로 전송한 수신 이미지에서 친구 추가하는 경우를 모두 확인. 글자 가독성과 QR 인식 결과로 실사용 규격 확정.

# 6 파일 정리 기록

- 정리일: 2026-11-16. 중국 출장 관련 작업을 중국출장 폴더 아래로 모으라는 사용자 요청 적용.
- 이전 위치: 90_작업 공간/중국 출장 디지털 명함.
- 현재 위치: 90_작업 공간/중국출장/명함/제작 기록.
- 검토 PNG 9개의 이동 전후 SHA-256 일치 확인. 기존 시각 검수 결과는 당시 기록으로 보존하며 이번 작업에서는 새 시각 검수를 수행하지 않음.
